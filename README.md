# Science Simulations

Classroom science simulations, published with GitHub Pages at
<https://cesarurania0580.github.io/science-simulations/>. Each folder is one
simulation, served at `…/science-simulations/<folder>/`.

| Folder | Simulation |
|---|---|
| `bottle-rocket/` | Bottle Rocket Lab |
| `paper-parachute/` | Paper Parachute Lab |
| `conductivity/` | Saltwater Conductivity Lab |
| `yeast/` | Yeast Respiration |
| `rutherford/` | Rutherford's Gold Foil Experiment |

**This repo is the published copy, not the original.** The originals live in the
teaching folders. To update one, copy its `index.html` (and `assets/`, if it has
one) into its folder here, run `git status` to see what is going up, then commit and push.
Never copy a whole teaching folder: they also hold teacher notes and answer keys,
and this repo is public.
